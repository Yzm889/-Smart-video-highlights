## 启动脚本 bat 编码乱码导致命令报错（14:21）
- 现象：双击 bat 报 `'PYEXE' 不是命令`、`'for' 不是命令`、`:765 不是命令` 等一串乱码错误。
- 根因：bat 被保存为 UTF-8 无 BOM，cmd 按系统 GBK 解析；中文多字节字符低位字节恰为 0x0A（换行），把注释行/for 循环从中间截断，后续 `for` 被当独立命令、变量未展开。我上一轮 Edit 把中文全角括号 `（）` 写进注释正好触发。
- 修复：用 Python `utf-8-sig` 重写 `启动视频工坊.bat`（文件头 EF BB BF，cmd 识别 UTF-8），去掉易碎中文全角括号；端口释放改用硬编码 `:8765` 避免 `%PORT%` 变量展开+冒号问题。已校验 BOM=ef bb bf。
- 经验：Windows 批处理若含中文，必须保存为 UTF-8 with BOM（或 GBK/ANSI）+ `chcp 65001`；Edit/Write 工具重写易丢 BOM 引发乱码，改 bat 优先用 Python `utf-8-sig` 落盘。

# 一帧成片 FrameCut — 前端设计交付

一套工业 / 仪表盘感（Industrial Instrument Panel）的前端设计系统，含三页可运行代码。

```
ui-lab/
├── index.html        产品落地页（非对称首屏 + 运行时仪表盘 + 五步导轨 + 规格表）
├── workbench.html    重塑的一帧成片工作台（素材 / 预览 / 时间线 / 参数 / 日志）
├── kit.html          组件套件页（8 类组件 × 8 种状态，可直接抄用）
├── styles/
│   ├── tokens.css    设计令牌：颜色 / 字阶 / 间距 / 圆角 / 阴影 / 动效
│   ├── base.css      重置、排版、焦点、氛围层、降级动效
│   ├── components.css 组件层（按钮 / 输入 / 开关 / 滑块 / 表格 / 控制台 / 空态…）
│   └── pages.css     三页布局与响应式
├── scripts/main.js   入场序列、滚动揭示、计数、步骤切换、Toast、日志、演示逻辑
└── README.md         本文件
```

运行：直接双击 `index.html` 即可；或 `python -m http.server` 后访问（推荐，剪贴板 API 需安全上下文）。

## 一、定调说明（Design Direction）

- **受众**：本机跑 AI 剪辑的创作者，装了显卡、不想把素材传给任何云服务；对"能不能跑得动、要多久、会不会崩"比"大而全的功能列表"敏感得多。
- **方向**：工业 / 仪表盘感。冷调近黑机身 + 发丝描边 + 等宽数字 + 琥珀警示色，整体像一台开着盖的渲染工作站，而不是一个 SaaS 营销页。
- **字体决策**：
  - 展示字 **Bebas Neue**（窄体大写，只用于拉丁标题与巨型仪表数字）
  - 铭牌 / 读数 **IBM Plex Mono**（全部数字启用 `tabular-nums`，读数跳动不错位）
  - 中文正文 **Noto Sans SC**（行高 1.75、字距 0.02em）
  - 三者分工不重叠，杜绝 Inter / Roboto / system-ui 这类默认字体。
- **配色决策**：主色是冷调近黑 `#0c0e11`（占 60%，机身），面板 `#151a21`（30%），
  唯一强调色琥珀 `#ff8a1f`（10%，只给关键动作与警示）。状态色（绿/黄/红）只出现在仪表读数里，不承担动作。
- **记忆点**：**危险条纹（hazard stripes）**。45° 琥珀/黑斜纹只出现在 CTA 上下两处；
  配合四角括号定位角、等宽铭牌标签（`STEP 01`、`A-01`）、以及会跳动闪烁的状态灯——
  访客能凭印象描述出来的就是"那台带黄黑警示条的黑色机器"。

## 二、设计令牌

改肤只需动 `tokens.css` 一处。核心令牌：

| 类别 | 令牌 | 值 / 说明 |
|---|---|---|
| 表面 | `--c-bg` / `--c-surface` / `--c-surface-2` | `#0c0e11` / `#151a21` / `#1c222b` |
| 文字 | `--c-text` / `--c-muted` / `--c-dim` | `#e9eef4` / `#93a1b1` / `#7b8896` |
| 强调 | `--c-accent` / `--c-on-accent` | `#ff8a1f` / `#0c0e11` |
| 状态 | `--c-ok` / `--c-warn` / `--c-err` | `#57d9a3` / `#ffc247` / `#ff6b5a` |
| 描边 | `--c-border` / `--c-border-strong` | `#263039` / `#38424e`（发丝 1px，绝不加粗） |
| 字阶 | `--fs-2xs` → `--fs-display` | 10 / 11 / 13 / 15 / 17 / 21 / 26 / 33 / 41 / 52px，`--fs-display` clamp(56,11vw,116) |
| 间距 | `--s-1` … `--s-9` | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px |
| 圆角 | `--r-sm` / `--r-md` / `--r-lg` | 2 / 3 / 4px（工业设备不做大圆角） |
| 阴影 | `--sh-1/2/3` + `--sh-inset` | Y 偏移 2 / 8 / 24px，带冷环境色；`--sh-inset` 做内嵌屏凹陷 |
| 动效 | `--dur-fast/base/slow/scene` + `--ease-out` | 160 / 320 / 640 / 780ms，`cubic-bezier(0.16,1,0.3,1)` |

`[data-contrast="high"]` 提供高对比分支（页头按钮可切），只覆盖语义令牌，组件代码不动。

## 三、动效规格（Motion Spec）

| 类型 | 实现 | 时长 / 缓动 |
|---|---|---|
| 首屏入场 | `.reveal[data-step="1..6"]` 错峰，`IntersectionObserver` 触发后加 `.is-in` | 640ms，组间隔 80ms，`--ease-out` |
| 数字滚动 | `data-count` 从 0 缓动到目标值 | 900ms，三次方缓出 |
| 按钮悬停 | 伪元素琥珀光带从左扫过（`translateX(-100%) → 100%`） | 320ms |
| 状态灯 | `lamp--live` 呼吸光晕 | 2.2s 循环 |
| 跑马灯 | `translateX(0 → -50%)` 无缝，悬停暂停 | 34s 线性 |
| 波形 | 12 根竖条错峰 `waveBeat` | 1.4s |
| 步骤命中 | `focusFlash` 琥珀描边闪现一次 | 1.2s |
| 降级 | `@media (prefers-reduced-motion: reduce)` 关闭全部动效，`.reveal` 直接可见，高亮改为静态描边 | — |

只动 `transform` 与 `opacity`，不触发重排。

## 五、可访问性自检

| 项 | 实测 |
|---|---|
| 正文对比度 | `--c-text` 15.6:1 · `--c-muted` 7.5:1 · `--c-dim` 5.3:1（均 ≥ 4.5:1） |
| 强调色 | `--c-accent` 对机身底 8.2:1；作为按钮底时配 `#0c0e11` 文字 8.2:1 |
| 焦点可见 | `:focus-visible` 2px 琥珀描边 + 2px 偏移，全站控件可 Tab 到达 |
| 触摸目标 | 按钮 `min-height: 44px`，小号按钮 34px 仅用于次级操作且间距 ≥ 8px |
| 语义结构 | `header / nav / main / section / footer`，每页唯一 `h1`，步骤条为 tablist 或 nav |
| 键盘操作 | 步骤条支持 ←/→/Home/End；片段 Enter/Space 可选中；跳过链接直达主内容 |
| 状态不只靠颜色 | 错误态同时给图标 + 文字说明；待确认片段标黄且写"待确认" |
| 降级动效 | `prefers-reduced-motion: reduce` 全量生效 |
| 响应式 | 1180 / 1024 / 760px 三档断点，工作台三栏依次降级为两栏、单栏 |

## 六、落地记录（已执行）

`ui-lab/` 是设计源，**其皮层已于 2026-09-08 迁移进 `static/style.css`**，现在两者视觉一致。

迁移方式为「只覆盖，不删除」——在原 style.css 末尾追加工业皮肤层，原有 1000+ 行选择器一行未删：

| 手段 | 作用 | 覆盖范围 |
|---|---|---|
| 变量重赋值 | `--accent` 金→琥珀、`--radius` 16px→3px、`--card` 玻璃→不透明面板 | 全站自动跟随 |
| 同选择器后覆盖 | 接管 `.btn` / `#go` / `.stepbtn` / `.gprog` 等硬编码金色 | 22 组组件 |
| 属性选择器 + `!important` | 接管 HTML 里 60 处 inline `border:1px solid #ddd` | 唯一能压过 inline style 的手段 |
| 伪元素氛围层 | `body::before` 工程网格 + `body::after` 噪点 + `header::after` 危险条纹 | 不动 DOM 结构 |

回滚：`C:/tmp/spring_video-stash/static-20260908/` 存有改动前的完整三件套。

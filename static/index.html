命令外号会不会看图干嘛用大小要不要装

最简：打开「🤖 AI 配置 → ③ 本地模型」，确认模型为 qwen2.5:latest，点「📥 拉取模型」即网页内一键下载（无需终端）。网络不稳就先在「🌐 国内下载镜像」填代理，或把模型改成更小的 qwen2.5:3b 再拉。

ollama pull qwen2.5:latest
嫌网页慢也可手动终端执行上面命令（复制即可）。想更小更快可填 qwen2.5:3b / qwen2.5:1.5b。 它只认文字：吃进「字幕 + 梗概」，吐出解说词。免费解说靠它干活，约 4.7GB，必装。

首次会下载约 4.7GB（7B 量化版），耐心等它跑到 100%。若 ollama pull 频繁断流、从头重下（Ollama 单层不支持断点续传），改用更稳的导入法：

① 用支持续传的工具先把 GGUF 下下来（免科学上网，-c 断点续传）：
aria2c -c -x8 -s8 -o qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf https://hf-mirror.com/Qwen/Qwen2.5-7B-Instruct-GGUF/resolve/main/qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf（满血 q4 第一分卷，约 4GB；再下 -00002-of-00002 第二分卷约 657MB）；
⚠ 坑：HF 上 q4_K_M 已被拆成两个分卷（-00001-of-00002/-00002-of-00002），没有单文件版，旧教程那种 q4_k_m.gguf 链接会 404。嫌麻烦就下单文件 q3_k_m（约 3.6GB，中文够用）：aria2c -c -x8 -s8 -o qwen2.5-7b-instruct-q3_k_m.gguf https://hf-mirror.com/Qwen/Qwen2.5-7B-Instruct-GGUF/resolve/main/qwen2.5-7b-instruct-q3_k_m.gguf；
② 分卷不要合并！llama.cpp 的分卷 GGUF 直接 copy /b 拼接会损坏（Ollama 报 split filename pattern 错）。Ollama 原生支持分卷导入：把两个分卷放同目录，Modelfile 写两行 FROM 分别指向它们即可（免合并）；
③ 新建 Modelfile（无后缀）放同目录：
满血 q4（两行 FROM，指向两个分卷）：FROM ./qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf + FROM ./qwen2.5-7b-instruct-q4_k_m-00002-of-00002.gguf；
或单文件 q3_k_m（一行，最省心）：FROM ./qwen2.5-7b-instruct-q3_k_m.gguf；
④ ollama create qwen2.5:latest -f Modelfile 导入本地；
⑤ 之后网页「③ 本地模型」自动识别。视觉模型（qwen2.5vl）直接在网页「⑤ VLM」点「📥 拉取模型」即可，不用手动下 GGUF。

🔊 本地配音引擎（免费·不花 API 钱） ↑ 上面「🌐 API云端配置」是付费配音路线，这里是免费本地路线，两条独立
三条免费路线怎么选？音质差别很大（点开）
· 🌐 edge-tts：情感+顿挫，微软神经语音，支持{情绪:xx}/{停顿:n}标记自动转SSML，不需要任何 Key。 代价是依赖网络，本机实测单次成功率约 2/3（连接会被随时重置），现已带自动重试。
· 🎭 CosyVoice：质量最高，阿里开源，接近商业级自然度，支持3秒声音克隆和情感控制。需GPU+约9GB模型。
· 🎙️ ChatTTS：很自然，本地GPU推理，对话式语音，支持停顿标记。需安装torch+ChatTTS（约3GB）。
· 💾 离线模型：下载后完全断网可用。两个可选：MeloTTS 自然度接近在线语音（推荐）； 华研 piper 体积小、速度快，但机械感重、几乎没有感情——觉得「配音像机器人」多半是选中了它。
· 🪟 系统 SAPI：零安装，但多数 Windows 只带一个中文音色（Microsoft Huihui），机械味重，仅作兜底。
选「自动」时优先级：edge-tts → CosyVoice → ChatTTS → 离线模型 → 系统 SAPI。 一条解说内部会锁定引擎，不会前半段一个声音后半段另一个。

# 字体目录

把中文字体文件（`.ttf` / `.otf` / `.ttc`）放进本目录，程序启动时会**优先**于系统字体使用它，无需改任何代码。

## 为什么需要

烧字幕和封面标题需要真正含中文字形的字体。程序会依次探测：
`SPRING_VIDEO_FONT` 环境变量 → **本目录** → 系统常见中文字体 → 系统字体目录扫描。
全都找不到时**中止渲染并报错**，不会静默改用不含中文的字体（那会画出一片「豆腐块」）。

## 推荐字体（SIL OFL 1.1 协议，免费可商用）

| 字体 | 说明 | 体积 |
| --- | --- | --- |
| [Noto Sans SC](https://github.com/notofonts/noto-cjk)（思源黑体） | 首选，字形清晰，适合视频字幕 | 单个字重约 10MB（Regular 即可） |
| 思源宋体 Source Han Serif SC | 偏文艺 / 古风画面 | 约 16MB |

下载后把 `NotoSansSC-Regular.otf` 之类的文件直接放进本目录即可。

## 关于默认字体

Windows 上默认命中的是微软雅黑（`C:/Windows/Fonts/msyh.ttc`），其版权归方正 / 微软，
渲染进**公开发布的商业视频**存在授权风险。若成片用于商业用途，请改用上表的 OFL 字体。

## 不随仓库分发的字体

字体文件体积较大，本目录**不预置**任何字体文件。需要离线 / 固定字形时再手动放入。
